# The name in product context

Every string below is the **real** current copy from `index.html`,
`manifest.webmanifest` and `shareGrid()` in `app.js`, with only the name
substituted. Nothing here is written to flatter a candidate — the point is to see
whether a name survives ordinary repetition, which a scorecard cannot show.

**Nothing in production has changed.**

---

## Halfsure

### The wordmark

```
[•] HALFSURE  #39                    🔥5  📊  ?
```

Currently `[•] BALLPARK #39`. **Both are eight characters**, so the topbar is a
literal drop-in — no layout work, no wrapping at 320px, no re-cutting the icon.
That is a small thing that is usually not small.

### Browser tab and OG title

```
Halfsure — the daily estimation game
```

### The installed app

```
name:        Halfsure — the daily estimation game
short_name:  Halfsure
description: Five questions a day. Don't guess the number — trap it.
```

The home-screen label is `Halfsure`. Eight characters fits on one line under an
iOS icon without truncation; iOS starts eliding around eleven.

### A shared result — the thing that actually spreads

```
Halfsure #39 — 340/500
🟩🟨🟥🟩🟨  🔥5
Beat me: https://playhalfsure.com/?d=39&s=340
```

And a perfect day:

```
Halfsure #52 — 468/500 🎯
🟩🟩🟩🟩🟩  🔥12
Beat me: https://playhalfsure.com/?d=52&s=468
```

The name sits in the same slot the score does, so it is read every time a result
is shared. It does not fight the number.

### Ordinary conversation

> Did you play Halfsure today?
> I got 3,800 on Halfsure.
> Today's Halfsure was brutal.
> Send me your Halfsure score.
> I've played Halfsure seven days straight.
> How are you that good at Halfsure?
> I'm on a nine-day Halfsure streak.
> Halfsure absolutely humbled me this morning.

**What repetition exposes.** It reads as a proper noun immediately — the
compound does the work that capitalisation alone would not. It does not become a
verb ("I Halfsured it") and does not want to, which is fine; neither does Wordle
for most people. The eighth sentence is the interesting one: *"Halfsure humbled
me"* is faintly self-describing in a way that flatters the game rather than the
player, and that is the emotional register this product actually operates in.

**Where it strains.** *"I got 3,800 on Halfsure"* is the weakest line, because
the name is quietly hedging while the sentence is boasting. It never becomes
wrong, but there is a small friction between a confident score and a name about
being unsure. Whether that reads as charming or as undercutting is genuinely a
taste call, and it is the honest thing to look at before committing.

## Nearbouts

### The wordmark

```
[•] NEARBOUTS  #39                   🔥5  📊  ?
```

Nine characters against eight. One character wider is nothing on desktop; at
320px the puzzle number sits closer to the streak flame than it does today.
Worth eyeballing on a phone before shipping, not worth worrying about.

### Browser tab and OG title

```
Nearbouts — the daily estimation game
```

### The installed app

```
name:        Nearbouts — the daily estimation game
short_name:  Nearbouts
description: Five questions a day. Don't guess the number — trap it.
```

### A shared result

```
Nearbouts #39 — 340/500
🟩🟨🟥🟩🟨  🔥5
Beat me: https://playnearbouts.com/?d=39&s=340
```

### Ordinary conversation

> Did you play Nearbouts today?
> I got 3,800 on Nearbouts.
> Today's Nearbouts was brutal.
> Send me your Nearbouts score.
> I've played Nearbouts seven days straight.

**What repetition exposes.** It is pleasant to say and has a slightly antique,
almost regional warmth — it sounds like a word your grandmother might use, which
is not a criticism. *"Today's Nearbouts was brutal"* scans better than the
Halfsure equivalent, because "Nearbouts" is a noun already and takes the
possessive naturally.

**Where it strains.** Spoken transmission is where it loses. Say *"Nearbouts"* to
someone and the honest odds are they write **nearabouts** — the dictionary's
preferred spelling of the same word — and that domain currently redirects to a
Dynadot for-sale page. Every voice recommendation has a real chance of landing a
new player on a domain listing. Halfsure's equivalent failure is a word-boundary
error, *"half sure"*, which search engines collapse and which no competitor owns.

---

## The comparison the mockups actually make

Both names survive repetition without becoming ridiculous, which is the low bar
and both clear it.

The difference is what happens at the **handoff** — the moment one person tells
another and the other person types something. That handoff is this product's only
compounding growth loop: 160 shares from 1,405 finishes, and every share carries
a challenge link.

- **Halfsure** mistyped → "half sure" → search collapses it → they find the game.
- **Nearbouts** mistyped → "nearabouts" → a for-sale parking page.

One failure mode is absorbed by infrastructure. The other is absorbed by a
domainer. That is not a scorecard row; it is the same failure Ballpark has now,
in miniature.
