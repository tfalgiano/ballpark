# Domain and handle checklist

**Execute manually. I have no purchasing tool and will not register anything.**

Everything here is brand *protection*, not channel launching. The purpose is that
nobody else can take the name while we are deciding — not to open seven marketing
channels we will never post to.

**Do none of this until the human spelling test passes.** If it fails, this list
is wasted money and the answer is Nearbouts.

## Do later, or not at all

| What | When | Why not now |
|---|---|---|
| `r/halfsure` subreddit | When there are players to put in it | An empty subreddit is worse than none. Reddit reclaims dead communities. |
| Discord server | Only if players ask for one | A vanity URL needs a Level 3 boosted server, so `discord.gg/halfsure` cannot be claimed yet regardless. |
| `@halfsuregame` defensively | Same sitting, if you want belt and braces | Free, and blocks the one obvious alternate string. Genuinely optional. |
| Bare `@halfsure` on X, Bluesky, GitHub | Same sitting, if convenient | Free, but do **not** build on it — it is taken on all five platforms where a game audience lives, so using it guarantees an inconsistent identity. Hold as a redirect only. |
| Twitch, Threads, Mastodon | No | We do not stream, and Threads binds to the Instagram username anyway. |
| `halfsure.gg` (~$52/yr), `halfsure.game` (~$340/yr renewal) | **No** | Recurring cost, wrong audience signal. Ten years of `.game` costs more than `halfsure.com` itself. |
| Typo domains (`halfshure`, `halfsur`, …) | No | The register work already cleared those strings and there is no traffic to defend. Defensive typo portfolios make sense at a scale we do not have. |

## Naming conventions, so this stays consistent

- **`Halfsure`** in all prose and product copy. Never *HalfSure*, *Half Sure*,
  *Half-Sure*, and never *HALFSURE* outside the wordmark.
- **`HALFSURE`** only as the styled wordmark in the topbar and on the OG card,
  matching the existing design.
- **`playhalfsure`** for every domain and handle.
- The product is **not** called "Play Halfsure." `play` is infrastructure. It
  appears in URLs and handles and never in a sentence.
- Tagline stays **"the daily estimation game"** for this release. One variable.

## Checks worth doing while you are in each signup flow

The handle research was done logged-out, and several platforms hide a 404 behind
a login wall. Confirm rather than assume:

- **Instagram**: whether "Profile isn't available" for `@playhalfsure` means free
  or deactivated. Deactivated names do not come back.
- **Threads**: binds to the Instagram username, so it should follow automatically
  — but confirm.
- **Discord**: a *username* is separate from a server vanity URL and is not
  checkable logged out.
